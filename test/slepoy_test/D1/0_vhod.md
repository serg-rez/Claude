# Замысел картинки — сцена c01

Я (мой принятый ИИ-аватар, карта персонажа v1.1) стою в своём небольшом складе, где храню товары для продажи на Ozon. За мной стеллажи с коробками. Держу перед собой двумя руками одну закрытую картонную коробку, смотрю в камеру, лёгкая уверенная улыбка. Кадр по пояс, вертикаль 9:16. День, свет из окна под потолком и потолочные лампы. На мне тёмно-синяя толстовка без логотипов. Кроме меня в кадре никого.

Дальше генератору промптов и генератору изображений передаются только мои референсы:
- HEAD_GRID — голова, лицо, волосы;
- BODY_GRID — телосложение и пропорции.
Исходного фото сцены нет — сцена создаётся по замыслу.
